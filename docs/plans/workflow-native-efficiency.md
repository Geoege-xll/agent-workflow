## 已决定方案

1. 扩展现有只读 doctor：声明能力与当前来源观察分开；AGY 的 diff／Artifact 审阅不能
   冒充专用 AI review。检查本项目明确的 `grill-me` 定义及覆盖风险，未验证的运行时来源
   明确未知，不扫描个人技能目录、不猜测命令命中，也不自动改名或改设置。
2. 新增无模型调用的原生用量读取入口。保持宿主字段语义，拒绝非法计数，按真实响应 ID
   去重，AGY 累计值按会话区分／差分；不把缓存读或推理子项重复加入总数。基线来自本项目
   已有 Codex 会话的已完成轮次，仅导出身份与用量元数据；不保存原提示或源代码内容。
   Claude／AGY 没有真实样本时如实记录缺口，不能填零冒充已采样。
3. 扩展原 `qa_handoff_cli.py`：导出原生结构化生成可用的 QA Schema，并解包宿主成功结果
   后继续原有语义校验。宿主 SUCCESS 不等于 QA PASS，部分／失败结果不得导入。
   已有 Task Pack 继续由任务图机械导出，不再启动模型仅为转换格式。
4. 在唯一任务图内增加可选的原生 Agent 引用。它只保存宿主及真实 Agent ID，不复制任务
   状态；续用查询依赖 PM 明确的当前宿主观察，不从保存 ID 推断存活、批准或完成。
   缺失、失效或取消的引用交 PM 恢复，不自动换 QA、派生新 Agent 或绕过 READY／QA 屏障。
