## 方案与原型关联

文档以稳定主题命名，后续迭代原位更新。进行中变更保留当前已验收基线，QA PASS 后才更新交付事实；Git 保存可恢复版本，完整日志留在请求证据区。未索引的历史执行材料不会因 completed 字样自动成为当前功能事实。

原型源模板位于 templates/prototype。设计 Agent 先在配置的 docs.standards_root/prototype 内制作工作区的可交互设计样稿，独立页面承载工作区这一产品界面及其模拟状态；经过既有用户最终视觉确认，再由生产 UI 实现者升级源模板。工作区导航由 index 维护一份，各实际业务页面继续独立 HTML。只为工作区当前页提供受控承载；页面和资源仍限制在原型根，新增需求导航仅允许明确关联的 plans 文件对。

设计 Agent 只负责配置原型边界内的样稿，返回需求覆盖、规范符合性和交付一致性自检；工具代码与文档模型由对应实现者负责。源模板属于这批实际 UI 实现，保留原型、具体页面指纹绑定的用户视觉确认、实现及唯一功能 QA；不能标为 non_ui 绕过。三个业务项目不因此被改写或获得视觉批准。
