## 目标与范围

修复 3.0.0-alpha.5 独立只读审计发现的三个闭环缺陷：Foundation 阶段审查与最终请求审查相互阻塞、工作树交付错误读取插件内置规范、PM 文档投影使用了错误的项目适配器根。候选版本为 3.0.0-alpha.6。

保留两步业务确认、主会话 PM 职责、唯一独立 Reviewer、原型流程与 Git 交付授权。此次不恢复中央运行时、TUI、Windows 适配，不扩展模型配置服务，不更新活动会话使用的插件缓存。

## 方案与原型关联

按职责分为两个不重叠的实施任务。Foundation 任务负责图模型、受保护阶段回执、导出与交接校验、调度准入、共用规范和对应回归；工作树任务负责资源分流、候选适配器与投影边界、真实插件布局端到端用例及测试入口注册。两者共享当前候选工作树，各自限定文件所有权；PM 负责集成、必要说明与验收证据。

阶段机制只服务 Foundation 审查，不引入通用阶段引擎。阶段产物仍经过原交接校验和原生执行状态核实，最终审查仍覆盖请求全部写入与实际集成候选。资源读取复用现有安全读取器，不降低路径和文件完整性检查。

此次没有界面变更，原型不适用。三平台安装、信任和派发能力边界沿用已核实的官方插件合同，不以单元测试冒充宿主实际模型运行。
