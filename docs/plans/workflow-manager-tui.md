# 工作流管理工具第一版

状态：八项修复的边界复审问题已完成修复，定向验证及独立复审通过。仅更新源包，未同步真实项目。

## 已确认范围

- 主界面为项目列表及角色模型表；Enter 编辑，Tab 切换分区，数字键切换平台。
- 工作流管理通过 g 进入，提供安装升级、检查、本地来源及备份恢复。
- 优先只读读取宿主配置及本地模型缓存，兼容代理工具写入宿主的模型目录；不请求模型服务、不复制凭据。
- 配置按项目、平台、角色隔离；预览后才备份应用，支持恢复；升级时保留项目模型配置。
- 三平台共用模型偏好入口，但字段按各宿主能力生成；Antigravity 仅使用官方角色档位。
- 原有需求/视觉确认、并行与 worktree、编译与运行、独立 QA 和收口规则保持不变。

## 实现选择

沿用源包已有 Python 3.11+ 运行时，终端界面使用标准库 curses，无新增包依赖。
管理器代码单独保存在 manager/，不复制进项目运行时；角色模型合同位于 lib/。
项目模型选择保存在现有 .agent-workflow/project.yaml 的 role_models 区块，升级自然保留。
项目列表和管理备份使用独立状态目录，默认 ~/.config/agent-workflow；测试重定向到临时目录。
显式选择模型或推理级别仅影响相应角色的配置，保留正文、工具、权限、Hooks 与编排合同。

真实项目不在本次验收范围内，不移动 worktree，不修改全局模型、凭据或会话记录。
