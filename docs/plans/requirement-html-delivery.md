## 实现选择

上游固定为 QingYunA/answer-me-with-html 的 `46fc8e8fc0edcdebfad8227d1eb849ca34e13fdc`，
当前 package 版本 0.5.10。bundled `scripts/am.mjs` 的 Git blob 为
`77be2073ff6ecaa3e20f73c4d10e7a28a19c942a`；约 1 MiB，Node >=20，本机已有 Node 22.23.2。
引擎与许可集中放在运行时 lib/vendor 下，避免给两个宿主 Skill 各复制一份；不安装上游 Skill 或其全局自动出页规则。

新增薄适配入口负责配置路径、Node 调用、固定输出、原子发布、并发变更拒绝与新鲜度检查。
禁用上游自动打开浏览器和后台更新，CLI 数据目录复用当前请求 scratch；不改变全局配置、模型或权限。
上游对任意 -o 位置会直接覆盖，因此先生成到本请求暂存，再用现有安全文件边界发布，保护原文及已有页面。
草案中的项目相对链接以未来 plans 下同名原稿为基准，仅在舞台副本重定位，批准后可按原字节保存正式稿。
当前采用受控 Markdown 子集：图片标记及原始 HTML 标签起始语法在整份原文中拒绝，代码示例也不豁免；普通段落、表格、flow/sequence 围栏和经检查的原型链接按需使用。
语法和渲染错误按原验证停止规则处理，不以措辞警告驱动无限重渲染。
