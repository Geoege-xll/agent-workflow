# 工作台工具外壳视觉统一

- 主题 ID：`workbench-solid-glass-style`
- 阶段：`completed`
- 模块：Agent控制台、原型交付外壳、原型评审工作台
- 任务等级：`Full`
- 已验收版本：`3.0.6`

## 目标与范围

按用户指定的[Solid Glass](https://github.com/deeplethe/solid-glass)统一工具视觉。用户明确交付原型只改工具外壳，画布内业务设计稿的字体、色彩、布局与交互不改。先完成原型并获确认，再实施生产；本地验收完成后按用户另行明确授权，已正式发布3.0.6／0.1.5并升级本机，见[发行主题](stable-product-release.md)。

本轮按用户明确批准的四项修复交付预览和实时评审的画布适配。以 mt-shop 的 `b02.html` 和 `a01.html` 提供可核对的真实输入，修改范围限定工作台外壳及其嵌入桥，采用原已确认视觉体系。

## 需求与验收

- REQ-901：Agent配置工具采用同一材质、排版和控件语言，保留用户／项目范围、调用偏好、原生定义、启停、诊断和两步保存；左侧角色列表只显示名称。
- REQ-902：交付页只调整工具栏、浮出目录、画布工具及进入评审入口；仍展示同一原稿，评审在另一网页打开，没有第二套完整设计稿。
- REQ-903：评审工具只调整工具栏、整改／标记列表、节点和页面整改弹窗；保持编号关联与修改／新增／删除语义，不恢复浏览模式、左目录、开发说明或意见等级，不增加节点拖拽。
- REQ-904：外壳与画布样式明确隔离。共享材质样式不泄漏到业务原型，原型内部按钮、表单和页面跳转按自身设计运行。
- REQ-905：搜索、选择、焦点、选中、禁用、错误和确认反馈采用同一尺度；不重新引入搜索框双焦点、重复手动准备或保存前手动刷新。
- REQ-906：交付与评审画布的普通滚轮／触控板滚动交由稿件自身处理，稿件到边界不接续平移画布。画布平移使用空格加拖动或中键，缩放使用Ctrl／Cmd加滚轮或工具按钮；保留画布聚焦时的方向键及空白区域原有触摸入口。固定设计视口与响应式可用视口分别处理，长内容不撑大iframe后再整页缩小；右侧清单独立滚动。
- REQ-907：交付页首次打开和「适应」在扣除底部工具条后的可用空间内把画板水平、垂直居中，保留能直接点击的手机底部导航。
- REQ-908：评审入口使用同一份相机适配，缩放、整改和定位工具的实际高度进入计算。工具换行、窗口尺寸变化、固定移动稿与响应式稿均保持已有手动相机、状态及定位交互的约定。
- REQ-909：交付、评审外壳的顶级纵向下拉刷新手势关闭，保留原型滚动区、既有滚轮／组合键行为和整改面板滚动。
- REQ-910：嵌入时只显示实际画板，原稿外围根／展示容器透明，使用工作台自己的画布颜色。原稿画板内背景、边框、状态栏、导航和单独查看时的样式按已有原稿呈现。

## 方案与原型关联

上游依据固定于提交`6e8903e494a15491ceda38fafea5056c95a74d44`。参考其厚实中性表面、细边缘高光、柔和层次阴影及克制状态反馈，不改用大面积透明、光晕或液态效果。实际复制的实质代码需保留DeepLethe的MIT许可及来源。

原型分别为`docs/standards/prototype/agent-configuration.html`、`prototype-delivery.html`和`prototype-workspace.html`，共享工具材质与控件样式。交付与评审通过独立文档画布复用同一稿件，不嵌套完整评审工作台。静态HTML适配现有语义结构，不为追求风格引入React、Tailwind、在线CSS或远程字体运行依赖。

生产材质和基础控件的单一规范来源为`templates/prototype/tool-theme.css`，许可随`solid-glass-LICENSE.txt`同包交付。配置组件与插件交付工具通过各自构建清单机械投影；配置、交付、评审各自保留布局与业务状态样式，公共主题限于`.sg-scope`工具根。独立组件使用固定本地静态路由，脱离源码仓仍具备完整资源闭包，不运行时引用源码目录或远程样式。

滚动尺寸和相机事件由既有`canvas-presentation.js`、`review-camera.js`负责，文件页与HTTP子稿桥只负责对应入口的有限消息与根滚动边界。父层持有最终视口，子稿自然内容高度不能改写父视口；不建立第二套相机、复制业务稿或全局禁用触摸。新手势演示只同步已批准原型的交互契约，保留原视觉批准记录。

本轮由父画布测量实际工具条遮挡边界，共享相机计算适应区域。只在当前受管嵌入阶段处理稿件外围与父外壳滚动边界。验收核对交付、评审真实元素边界、窄屏工具换行、滚动和背景计算值，并复验业务原稿保持同一份来源。

## 验收结果与当前已交付行为

- 以哈希一致的 `mt-shop` A01、B02 原稿副本在 macOS Chromium 实测。两入口首次打开及「适应」均在可用区水平、垂直居中，实测场景中底栏与工具相距 24 CSS 像素，底部导航可点。嵌入外围透明，稿内主题和单独查看时的原始样式保留。原稿两份 HTML 和两项依赖的哈希前后一致。
- 保留稿内滚动、右栏独立滚动、标记定位、Ctrl／Cmd 滚轮及中键平移。极短窗口可用工具按钮和组合滚轮双向缩放，Tab／Shift+Tab 实测使最后的 44 像素按钮完整进入视口。手机原生下拉刷新手势、读屏与其他浏览器引擎未做真机验证。
- 37 项定向测试通过。唯一独立 QA 首轮复现低于 8% 后无法缩回，修复后重跑浏览器负载与回归并接受最终 13 路径冻结差异 `93f8e9843a6a2a008e56188819fe7b6f4196b2bf1084ac796503b29d2dfe44f4`。三个宿主候选的 12 项画布资源逐字节匹配。结果与摘要见[本地验收证据](../../dist/evidence/solid-glass/canvas-20261119/evidence.sha256)。
