Page design and interaction contract

页面职责

对应 REQ-001 至 REQ-006。只细化当前项目工作流管理条与正文分隔；复用 manager/tui_support.py 的粗外框、轻横线／轻竖线、Theme 青色焦点／反色选择／文字状态，以及 manager/tui.py 的平台和区域语义。Platform: terminal (curses). Display: fixed. 常规基准 100 columns × 30 rows，900×660 CSS px；紧凑基准 55 columns × 16 rows，495×352 CSS px。两者均为每格 9×22 CSS px、1:1、15px 本地等宽字体；外层不足时横向滚动画布，不做比例缩放。

常规管理行位于第 4 行（从 0 起）：左为“项目工作流＋文字状态”，中为当前项目，上下文独立限宽，右为固定的 [o]启用工作流／[p]停用工作流入口；第 5 行完整轻横线以“┠／┨”连接粗框，第 6 行统一显示“项目列表／角色模型”主标题，第 7 行为数量、当前项目及平台／未保存信息，第 8 行在两栏内加轻分隔，之后开始项目列表与角色表。紧凑管理条占第 4、5 行，第 6 行完整分隔，第 7 行合并当前区域主标题、辅助信息和计数，不另占分隔行；正文保留当前条目。角色内容与其它旧流程仅提供必要背景。

导航

本具体页只在 index.html 的唯一 nav#prototype-pages 登记一次；旧 prototype-workspace.html 入口保留。工作区仅承载当前页；圆形返回展开侧栏和当前分组、聚焦当前入口并保留页面。独立打开时返回本页登记深链。侧栏开关仅改变外部展示工作区。需求对由唯一文档导航另开窗口，不替换预览。

浏览器默认保留正常 Tab 顺序。聚焦任一终端并按 Enter／Space，或点击其产品控件后，才进入该终端按键模式；Tab／Shift+Tab 循环切换下／上平台，1／2／3 也可直达。← 固定聚焦项目、→ 固定聚焦右侧内容，重复同方向不反转；↑／↓ 在当前区域选择并在边界停留。项目 Enter 进入角色区；角色 Enter 仅说明未演示模型编辑。Esc、F6、q 释放按键，焦点留在终端，后续 Tab 回到普通网页导航；预览内 Esc 只取消当前预览。

原生契约 summary：点击／Enter／Space 展开或折叠这五节，默认折叠，不覆盖产品画面。

打开同名正式需求 HTML，新窗口阅读，不改变当前原型。

状态

已启用示例：#normal-management-status 初始显示“项目工作流 已启用”，#normal-project-context 指明当前演示项目，#normal-content-divider 是管理条下完整轻线；#normal-simulation-result 明示页面模拟。左栏反色为活动选择，角色区非活动选择仅以“›”和字重提示；→ 后切换为角色反色。

已停用／长名称示例：#compact-management-status 初始显示“项目工作流 已停用”，#compact-project-context 按剩余字符格截断，#compact-content-divider 留出独立横线。→ 内容区显示“工作流未启用 · o 启用工作流”，解释空内容而非加载失败；← 恢复项目选择。

工作流变更预览：#normal-preview-modal／#compact-preview-modal 初始 hidden，o／p 打开时以 #normal-preview-change／#compact-preview-change 展示原状态与目标状态，取消不变，确认仅更新本页示例。#normal-simulation-result／#compact-simulation-result 始终返回“页面模拟”反馈。相同状态仍可预览，确认提示状态维持；无隐藏的实际执行。

两画板状态彼此独立。切换项目、平台与区域不会修改其它项目状态；角色选择按项目／平台在页面内保留。刷新重置。控件具有默认、hover、pressed、selected 和可见焦点；选中靠反色和文字标记，停用靠文字。当前静态数据不涉及权限、加载、网络错误、提交中或部分数据，故不添加虚构状态；旧流程按键给出未演示提示，不清空模拟状态。
