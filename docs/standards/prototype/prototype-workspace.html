Page design and interaction contract

页面职责

本页是“原型浏览工作区”这一产品界面的虚构高保真交互设计样稿，覆盖 REQ-004、REQ-005 和 REQ-006 的可见设计范围。Platform: Web. Display: responsive. 页面按可用宽度自然展开，使用 CSS px，不采用固定设备窗口；窄空间将侧栏移到内容之前，列表保留可读顺序。

候选产品 token 集中在 prototype.css 的 --workspace-*，仅适用于本样稿；外层 --prototype-* 复用模板中性展示基线，不宣称项目已采用新主题。真实需求为 docs/plans/workflow-document-lifecycle.md 及其同名 HTML。

导航

index.html 的唯一 nav#prototype-pages 登记本独立页面，隐藏登记导航后以唯一 iframe#prototype-preview 直接承载本页，不展示独立目录或附加头部。本页也可按独立 HTML 路径直接打开。

产品区三个锚点只是本页的虚构预览状态，未登记额外独立页面，也不代表生产模板的文件导航协议；同页状态不拆新文件。工作区圆形返回负责展开侧栏并聚焦当前入口，与侧栏开关独立，不再提供外层目录返回。

右侧画面后的 nav.prototype-requirement-links 只提供已绑定主题的 HTML/Markdown 两个普通相对导航链接；两者以 target="_blank" 在独立标签页或窗口打开，并用 rel="noopener" 隔离来源窗口访问，不替换当前预览或顶层工作区。没有脚本读取文档、跨文档 DOM 或资源预载。具体页不含 iframe；入口的静态本地承载仍须验证登记目标与既有资源闭包，生产多页面切换与安全路由由后续实现者完成。

交互

返回当前页面导航：展开侧栏及当前页面所在原生分组，保留当前预览，并将焦点移到当前页面链接；状态区宣布当前定位结果。

收起/展开侧栏：点击或 Enter/Space 切换侧栏可见性，aria-expanded 与按钮名称同步更新，右侧预览扩展或恢复；不改变当前页面和分组状态。

文档中心分组：原生 summary 通过点击、Enter 或 Space 切换 details 的展开状态，不切换当前页面。

文档概览：点击或 Enter 选择 demo-overview，同步标题、简述、分组名称、唯一 aria-current 和“当前”文字标记；显示对应画面并聚焦页面标题。

需求详情：点击或 Enter 选择 demo-requirement，按同一规则更新当前页面与预览，其他示例画面隐藏。

原型浏览分组：按原生 details/summary 方式折叠或展开，不改变当前预览。

页面说明：点击或 Enter 选择 demo-guidance，同步选中反馈、页头与只读说明画面。

阅读需求：点击或 Enter 在独立标签页或窗口打开现有 ../../plans/workflow-document-lifecycle.html，保留当前工作区；它是正式需求导航，不是预览依赖，新文档不能通过 opener 访问来源窗口。

需求原稿：点击或 Enter 在独立标签页或窗口打开同主题 ../../plans/workflow-document-lifecycle.md，保留当前工作区并隔离 opener；由浏览器按本地 Markdown 支持方式展示、下载或交给关联应用。

页面设计与交互契约：原生 summary 展开或折叠样稿内的页面说明，不覆盖预览或占用浏览器固定浮层。

本页契约：原生 summary 展开或折叠这五节实际设计契约，默认折叠；位于产品插槽之外。

状态

初始状态为侧栏展开、两个分组展开、文档概览选中，内外契约均折叠。合法的本页示例锚点可恢复对应选择；未知锚点不会成为页面路径或加载目标，回到默认示例。

切换页面时只有一块示例画面可见，标题与导航一致；选中既有颜色也有“当前”文字，键盘焦点独立显示。收起侧栏后右上角保留展开按钮；返回当前导航会恢复侧栏、展开对应分组并移交焦点。打开任一关联需求文档不会替换当前预览或顶层工作区，当前页面选择、分组及侧栏状态保留。

控件具有默认、hover、pressed 和 focus-visible 状态，链接有当前选中状态；遵循 reduced-motion。此样稿没有异步请求、提交、真实账户或业务写入，因此加载、提交成功、业务错误、空列表、禁用和弹窗状态不适用，不制造假成功反馈。

窄屏通过自然换行和单列布局保留必要操作；没有固定页面高度、远程字体或图像。静态检查不能证明实际渲染、键盘实操或辅助技术效果，默认没有调用浏览器及截图。

例外

本页按当前批准的设计任务在产品插槽中模拟未来工作区；三个预览状态不是业务项目交付页。设计入口只实现单登记页的静态本地承载，不实现生产模板的多页面控制器，不修改源模板，不新增搜索、编辑器、拖拽或截图功能。样稿内页面说明与产品区外实际五节契约分离；除此之外没有页面特例。

当前只呈现候选视觉，用户最终视觉确认由 PM 处理；静态验证或演示内容不代表需求已实施或项目已验收。
