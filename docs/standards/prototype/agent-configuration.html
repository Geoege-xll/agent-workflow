Page design and interaction contract

页面职责

Platform: Web. Display: responsive. 响应式本机配置工作台，桌面为横向工具栏、单行默认设置与精细表格，窄屏重排为单列字段；无固定窗口。REQ-101—REQ-106：顶部平台、统一范围、三导航，模型首屏；通用默认、逐身份调用偏好、高级原生定义与独立启停；渐进诊断与底部预览保存（桌面随当前操作区吸附，窄屏自然排列）。产品 token 复用现有 --workspace-* 语义，单一蓝色强调；平台为顶层下划线 Tab，范围为中性原生 radio 分段，功能为二层文本导航；通用默认与 Agent 表格以同一 28%/30%/22%/20% 列变量和相同 16 CSS px 单元格内边距对齐；模型选择使用统一的原生控件视觉封装，按钮/选择框/披露触点至少44 CSS px。无新增全局规范。

导航与范围

REQ-101：初始 Codex／用户级／模型与推理／调用偏好。平台、范围、三分类与高级原生入口原位切换；切换反馈是中性短时状态（4秒），持续的当前对象、分类草稿计数及保存栏仍可定位草稿；所有草稿按平台×范围（项目含演示绝对路径）×调用偏好/原生/启停独立存于内存，返回原范围继续编辑。统一范围栏始终显示当前编辑对象；项目位置按需展开。顶部 tab 支持左右/Home/End 自动激活与 Enter/Space；横向分类为普通原生按钮。圆形返回与侧栏开关复用 page-shell.js；index仅登记此普通相对链接。需求 Markdown 单独打开。

状态与恢复

REQ-102：模型变更按有效模型重算推理候选，保留不兼容原值并就近报错；重选或恢复继承后才可预览。批量 effort 使用所选有效模型的交集，不使用并集。Codex 零身份空态保留可编辑通用默认；Claude 原生插件缓存只读；AGY 完整会话模型仅出现在目录说明，不能成为子代理 tier。

REQ-103、REQ-104：启停有已保存值、本层草稿与继承结果，AGY启停明确不支持。所有编辑只改草稿。预览只包含当前事务，取消/Esc/关闭保留草稿；确认模拟保存期间按钮禁用、状态可读，成功只清除对应草稿并明确本页内存模拟；保存栏持续呈现该事务保存记录与后续派发读取/新会话加载及实际运行未验证边界。来源冲突拒绝旧预览，关闭后重新读取、再次预览；部分发布显示逐项收据，保留前像与未保存草稿，可模拟恢复已发布项，再返回重新预览。恢复不删除唯一收据，不把部分写入称为全部回滚。
