页面职责

Platform: Web. Display: responsive. 第六版深石墨专业配置工具。顶部单条上下文带集中平台、用户/项目范围与项目位置；148 CSS px窄功能导航仅组织模型、启停、诊断三项；右侧单一编辑平面呈现默认规则和逐身份覆盖，底部为当前事务提交区。不叠多排Tab/分段，不做大侧栏、IDE装饰或卡片拼装。REQ-101—106、REQ-701—703：产品区固定color-scheme: only dark，与系统浅色无关；页面、组件、悬停、选中、文字与必要边界使用同一组语义token，单一克制蓝色强调。正文14px、辅助13px；默认和表格共享29%/31%/22%/18%列线及16px单元内边距。主按钮、输入、上下文披露和选择器外高最小36 CSS px，辅助操作32 CSS px，窄导航统一38 CSS px；触屏主控件48 CSS px，其余必要目标至少44 CSS px。控件随文字增长。窄容器将导航收成单行、字段重排，不隐藏保存和上下文。Codex零身份为短空态，不伪造角色或撑高列表。本版尚无用户视觉批准或生产实现。
