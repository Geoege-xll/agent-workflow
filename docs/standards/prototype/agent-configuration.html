Web · responsive · CSS px · SolidGlass 中性工具原型

演示说明使用虚构模型目录、项目与发现身份，刷新页面即重置。Codex 演示从 xy-config open 自动补齐后的 7 个内置角色；Claude 演示别名；AGY 子代理仅演示 flash/pro tier。模拟刷新、保存和恢复均不请求服务或改写磁盘；没有模型运行验证。本轮仅完成静态校验，未经过浏览器操作与视觉验收。此文件可离线操作；本轮交付外壳见 prototype-delivery.html，独立评审见 prototype-workspace.html。两者只演示工具界面，不连接服务，不导出真实评审协议。

Page design and interaction contract

页面职责

Platform: Web. Display: responsive. SolidGlass 中性烟灰材质的紧凑配置工具。顶部单条上下文带集中平台、用户/项目范围与项目位置；148 CSS px窄功能导航仅组织调用偏好、原生定义、启停、诊断四项；右侧单一编辑平面呈现默认规则和逐身份覆盖，底部为当前事务提交区。不叠多排Tab/分段，不做大侧栏、IDE装饰或卡片拼装。REQ-101—106、REQ-701—703：产品区固定color-scheme: only dark，与系统浅色无关；页面、组件、悬停、选中、文字与必要边界使用同一组语义token，中性主操作与同一选中态；修改/新增/删除的语义色只属于评审工具。正文14px、辅助13px；默认和表格共享29%/31%/22%/18%列线及16px单元内边距。主按钮、输入、上下文披露和选择器外高最小36 CSS px，辅助操作32 CSS px，窄导航统一38 CSS px；触屏主控件48 CSS px，其余必要目标至少44 CSS px。控件随文字增长。窄容器将导航收成单行、字段重排，不隐藏保存和上下文。Codex 采用启动入口自动补齐后的七个内置定义样本；不会在网页加手动准备控件。本版尚无用户视觉批准或生产实现。

导航与范围

REQ-101、REQ-701：初始Codex/用户级/调用偏好。平台与范围为顶部两个原生details披露，当前名称始终可见，最多展开一个。平台候选保留Tab语义，方向键/Home/End只定位，Enter/Space才激活并收起回到平台入口；范围保留原生radio，选择后收起回到范围入口。项目位置按需展开，接受atlas/orbit样本路径，项目范围名称包含当前项目。四个功能入口集中在148px窄导航；原生定义与调用偏好在窄导航并列；原生定义左侧只展示名称，右侧展示所选定义与字段，搜索只保留一个输入框。草稿按平台×范围（项目含绝对路径）×调用偏好/原生/启停隔离并保留；切换回执4秒，当前事务与草稿数在提交区持续显示。上下文披露Esc关闭并回焦点，点击外部或焦点离开关闭。选择浮层遵循独立复合控件契约。需求Markdown独立打开。原稿不维护页面目录或返回index入口。本轮 prototype-delivery.html 的目录默认收起，缩放只影响画布；“进入评审”以 noopener 独立新网页打开 prototype-workspace.html 的当前视图。file:// 可直接操作原稿和本轮工具外壳。

状态与恢复

REQ-701：顶部上下文和窄功能导航各司其职，默认规则/逐身份同列，角色按实际发现样本列出。相同模型/推理来源只显示一次，草稿仍保留已保存前像，状态不只靠颜色。REQ-702、REQ-703：选择浮层的搜索/无结果/选中/活动/未知/自定义、禁用与处理中状态可演示；Popover特性检测后增强，无原生Popover则用相同语义、键盘与有界固定定位回退，不请求CDN。模型改变重新计算其元数据；未知模型只提供标为能力未核实的工具合同候选，可编辑、预览与模拟保存，批量不将这些未核实值混入已知能力交集。REQ-102：模型变更按有效模型重算推理候选，保留不兼容原值并就近报错；重选或恢复继承后才可预览。批量 effort 使用所选有效模型的交集，不使用并集。Codex 七个内置身份与通用默认均可编辑；Claude 原生插件缓存只读；AGY 完整会话模型仅出现在目录说明，不能成为子代理 tier。

REQ-103、REQ-104：启停有已保存值、本层草稿与继承结果，AGY启停明确不支持。所有编辑只改草稿。预览只包含当前事务，取消/Esc/关闭保留草稿；确认模拟保存期间按钮禁用、状态可读，成功只清除对应草稿并明确本页内存模拟；保存栏持续呈现该事务保存记录与后续派发读取/新会话加载及实际运行未验证边界。来源冲突拒绝旧预览，关闭后重新读取、再次预览；部分发布显示逐项收据，保留前像与未保存草稿，可模拟恢复已发布项，再返回重新预览。恢复不删除唯一收据，不把部分写入称为全部回滚。

REQ-105、REQ-106：目录刷新显示进行中/成功/失败，失败保留模型与草稿；重新读取不丢草稿。已保存、后续读取/等待重新加载与实际运行未验证分别表达。固定深石墨产品区与系统外壳分离、可见焦点、原生dialog的模态背景/焦点围栏/Esc与返回焦点已设计，尚未在浏览器实际操作；响应式、缩放、读屏与完整可访问性行为未实测。

边界与页面特例

本页没有额外产品特例。演示数据不代表本机发现，原稿业务不调用真实API、不写真实配置、不安装或启动服务。三类事务与四层调用偏好继承遵循已交付合同；完整原生定义仍按宿主官方优先级，插件缓存不可写。AGY独立推理与派发schema未核实，不能生成未经证实的调用参数；停用恢复命令使用明确不可执行的演示路径。具体页复用 prototype.css，SolidGlass token、148px布局与局部JS仅影响本页工具。交付和评审的共享CSS只能作用于工具外壳，iframe 中业务字体、色彩、布局和交互保持原稿。本轮 prototype-delivery.html 与 prototype-workspace.html 是工具自身的静态交互原型，读取同一物理原稿；iframe sandbox 仅 allow-scripts，节点选择使用有限 postMessage，既不读跨文档 DOM，也不生成正式反馈协议。本轮不运行或改写正式交付服务，不提供服务冷启动或端口发现，原稿不嵌认证、机器绝对路径或随机端口。正式交付与评审运行时仍保持原有独立入口与连接合同，须待本轮视觉确认后再实施风格迁移。评审进入即批注，临时操作按工具提示使用修饰键并在释放后回到批注；评审意见不等同需求或视觉批准。静态PASS仅为visual_review_ready，用户视觉批准与生产实现仍待后续。
