# Impeccable 设计方法

在当前设计任务按需选择此入口，只使用随包原文与适用参考。原型仍由 `xy-uiux` 按项目规范设计，
由 `xy-prototype-verify` 静态验证。原文中的安装、引擎、浏览器与 hooks 指令不属于此入口的执行权限。

从当前物理插件根读取 `platforms/shared/skills/xy-workflow/references/skill-selection.md#impeccable-design-guidance`，
依其分页合同读取已锁定的正式分发正文与所需参考。

`platform-design-skills`。随包附[完整 MIT 许可证](platform-design-skills-LICENSE.txt)。[固定上游原件](https://github.com/ehmo/platform-design-skills/blob/dc2be825d8b439caea78e9eaa8fb3ac23b0ff3e9/LICENSE)
