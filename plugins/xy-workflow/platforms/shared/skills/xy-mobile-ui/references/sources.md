## 官方依据

- Apple 的安全区、窗口布局、控件尺寸、Dynamic Type、VoiceOver 和减少动态效果依据 HIG。SwiftUI 与 UIKit 的实现以项目使用的 SDK 和 API 文档为准。Apple 官方资料按各页面及站点条款使用。 [HIG 布局](https://developer.apple.com/design/human-interface-guidelines/layout) · [HIG 无障碍](https://developer.apple.com/design/human-interface-guidelines/accessibility) · [SwiftUI `safeAreaInset`](https://developer.apple.com/documentation/swiftui/view/safeareainset%28edge%3Aalignment%3Aspacing%3Acontent%3A%29) · [UIKit `UIKeyboardLayoutGuide`](https://developer.apple.com/documentation/uikit/uikeyboardlayoutguide)
- Android 的窗口 Insets、边到边布局、返回、状态收集与无障碍使用 Android Developers 的平台指导。站点文档和示例代码通常适用 Apache-2.0，以页面标注的例外为准。其他 Google for Developers 站点文档与示例按各自页面许可判断。 [Compose Insets](https://developer.android.com/develop/ui/compose/system/insets-ui) · [Views 边到边](https://developer.android.com/develop/ui/views/layout/edge-to-edge) · [预测式返回](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture) · [架构建议](https://developer.android.com/topic/architecture/recommendations) · [Compose 无障碍默认行为](https://developer.android.com/develop/ui/compose/accessibility/api-defaults) · [Android 无障碍测试](https://developer.android.com/guide/topics/ui/accessibility/testing) · [Android Developers 许可](https://developer.android.com/license) · [Google for Developers 站点条款](https://developers.google.com/terms/site-policies)
- 微信小程序窗口信息、键盘事件、路由 API 和页面生命周期参考微信小程序维护的类型声明，自定义导航的胶囊避让参考 WeUI 小程序组件的实现。两库采用 MIT。实际能力以项目基础库、渲染器与客户端为准。 [API 类型声明](https://github.com/wechat-miniprogram/api-typings/blob/e5dc50ccea71e7999a8aa8a942a6f68045e141ca/types/wx/lib.wx.api.d.ts) · [页面类型声明](https://github.com/wechat-miniprogram/api-typings/blob/e5dc50ccea71e7999a8aa8a942a6f68045e141ca/types/wx/lib.wx.page.d.ts) · [类型声明许可](https://github.com/wechat-miniprogram/api-typings/blob/e5dc50ccea71e7999a8aa8a942a6f68045e141ca/LICENSE) · [WeUI 导航栏](https://github.com/wechat-miniprogram/weui-miniprogram/blob/5d04cad87bf9305d709aa1b623b8f34f2c659a2d/src/components/navigation-bar/navigation-bar.ts) · [WeUI 许可](https://github.com/wechat-miniprogram/weui-miniprogram/blob/5d04cad87bf9305d709aa1b623b8f34f2c659a2d/LICENSE)
