# 移动端共享规则

适用于 iOS、iPadOS、Android 原生界面和微信小程序。按当前任务、已批准要求和项目规范选用下列条款，条款 ID 用于交接定位。用实际容器和平台能力解释行为，具体实现参考对应平台文档。

## 在现有页面契约中记录

在已经授权的 HTML 原型中沿用 [Page design and interaction contract 五段格式](../../xy-ui-design/references/prototype-canvas.md)，契约正文用英文、可见产品文案用项目语言。选择适用的行为写入对应段落。具体控件的条目沿用稳定 `id` 和对应的 `data-contract-for`。

| 现有段落 | 移动端行为如何填写 |
| --- | --- |
| `purpose` | 当前页面目标、实际目标平台和演示视口。沿用页面的显示方式，固定画板记基准设备／窗口与尺寸。 |
| `navigation` | 页面入口、目标、返回目的地及弹层、键盘和页面栈的处理顺序。全局导航与页面内操作写明各自职责。 |
| `interactions` | 控件触发、输入焦点和滚动、固定栏出现条件及底部空间由哪个容器预留，注明读屏名称、角色或动作中需要明确的行为。 |
| `states` | 适用的加载、空、内容、错误和提交状态，切换或重建后保留什么。键盘、较大字体、读屏焦点和减少动态效果造成的状态变化按影响填写。 |
| `exceptions` | 受支持目标中的平台差异、窗口过小或遮挡时的回退、异常返回路径，以及 HTML 只表达意图、需要原生证据的行为。 |

HTML 中实现能够在同一工作区演示的交互结果。系统栏、键盘形态、手势、生命周期和无障碍服务在 HTML 中可以模拟状态和预期结果。实现者在现有构建验证交接中给出对应平台运行证据，区分模拟器／仿真器与真机，写明环境和实际观察。QA 按受影响行为核对页面契约、生产代码和已有证据。选用最能判断问题的设置和设备，缺少实际运行证据时记录未覆盖的行为。

## 安全区与键盘 `mobile-insets-001`

- **适用**　页面覆盖到系统边缘，存在滚动、标签栏、固定操作栏或文本输入，或父子容器共同处理遮挡。
- **契约**　在 `purpose` 写基准视口，在 `interactions` 写背景延展和承载可操作内容的容器，指明固定栏与滚动区域的边界。在 `states` 写键盘开合时栏位置、焦点和滚动结果，在 `exceptions` 写窄窗口或悬浮键盘等适用限制及回退。
- **实现**　对同一屏幕边、同一类遮挡，在同一布局链上指定一层负责把原生安全区或键盘 Insets 转换为布局空间。保留父容器已处理的空间，子容器只使用未处理部分或自身组件实际高度。背景可以延展。贴底栏占用滚动可视区域时，让容器布局自动腾出空间，或由滚动区一次性预留栏高。输入焦点和滚动配合，使当前字段、最后一项及主操作可达。键盘遮挡过大时，按契约使用可滚动区域或明确的收键盘路径。
- **证据**　记录实际负责层及父子间传递方式。原生运行时在有代表性的系统栏和输入法设置下滚到末项，切换焦点并开合键盘，核对无双重留白、无栏后遮挡，且主操作可触发。横屏、分屏或悬浮键盘影响本页时才补相应条件。

## 导航与返回 `mobile-navigation-001`

- **适用**　更改导航栈、顶级标签、详情入口、可关闭的浮层或编辑退出逻辑。
- **契约**　在 `navigation` 写顶级与下钻目标、返回级别和返回后的落点。在 `interactions` 对按钮与适用的系统返回各写可观察结果。在 `states` 写标签选中和恢复的页面状态，在 `exceptions` 写浮层、键盘、未保存编辑与根页面的优先顺序和触发条件。
- **实现**　沿用实际路由栈和系统组件。只在对应状态拦截返回，使一次动作处理一个层级。预览或取消交互式返回时保留原路由与数据，提交时才完成跳转。顶级入口状态和各自导航栈按已批准行为保留或重置。
- **证据**　用原生按钮和受支持的系统返回方式走详情往返、标签往返或浮层关闭。涉及交互式手势时验证一次取消和一次提交，检查路由、选择状态和编辑内容。覆盖本次变更实际影响的入口。

## 状态生命周期 `mobile-state-001`

- **适用**　页面读取异步数据或共享状态，有提交、筛选、滚动恢复、页面重进或配置变化等行为。
- **契约**　在 `states` 写可见状态、转换条件、需保留的草稿／筛选／滚动锚点，在 `interactions` 写触发、禁用和重试结果。在 `exceptions` 区分离页重进、窗口重建及需求明确支持的进程重建等回退场景。
- **实现**　由实际架构中的状态所有者提供可渲染状态。页面的订阅与资源按生命周期绑定，一次性动作在预期的交互或生命周期事件触发。用合适的保存边界恢复状态，保留时长以需求为准。复核重复提交和异步结果晚于导航的情形，避免已离开的界面处理迟到结果或重新显示时重放动作。
- **证据**　检查状态所有者、订阅生效／停止点和恢复边界。运行受影响的首进、离开返回、后台前台或重建，观察加载、恢复、错误与重试是否符合契约，以及是否产生重复提交或过期结果覆盖。

## 无障碍 `mobile-accessibility-001`

- **适用**　新增或改变交互控件、标签、状态提示、文字布局、焦点或自定义动画。
- **契约**　在 `interactions` 写有效触控区域、必要的读屏名称、角色和值及焦点顺序。在 `states` 写较大字体下的重排或滚动、错误或选中状态的播报，以及适用的减少动态效果表现。在 `exceptions` 写紧凑布局、手势交互或动效的可用替代路径。
- **实现**　优先保留原生控件的可访问语义。检验有效命中范围和邻近目标是否冲突，平台尺寸参考各自指导。文本随系统字体设置变化并允许布局适配。错误、选择和执行结果有可辨识的文本或语义，焦点与可见顺序一致。自定义位移、缩放或重复动画受相关系统设置影响时，提供静态或低运动形式并保留同一操作结果。
- **证据**　在适用的较大字体下核对文案与主要操作仍可达，确认相邻目标能独立触发。用 VoiceOver 或 TalkBack 核对路径中的名称、角色、状态和焦点，包括弹层关闭后的落点。本次改变动效时，验证开关减少动态效果后的结果和反馈。

## 契约消费示例

以下两例展示现有契约如何向开发及 QA 交接。实际页面取项目的视口、名称和已批准行为。

### 带固定提交栏的表单

- `purpose`　编辑资料，使用选定手机画板展示较长表单、固定提交栏和键盘开合。
- `navigation`　从资料页进入。返回时依次处理可见模态、系统键盘和离页。页面已修改且要离开时提示保留或舍弃，保留编辑时焦点回到原字段。
- `interactions`　滚动区由页面容器留出提交栏空间。聚焦最后一项时，滚动到字段与错误提示；提交栏位于停靠键盘上方，仍可执行。校验失败聚焦首个无效字段。
- `states`　编辑、校验错误、提交中、明确失败、结果未明和完成。提交中禁用再次提交。明确失败时保留输入，按项目约定允许重试。超时或断线导致结果未明时保留输入，先按项目已有机制确认结果或恢复处理，避免重复写入。提交完成回到资料页。
- `exceptions`　窄窗口若无法同时展示字段和提交栏，允许滚动到字段并由明确操作收起键盘后提交。HTML 演示焦点、键盘状态与提交结果。原生交接验证负责层、键盘开合前后末项及提交、明确失败后保留输入、结果未明时先确认或恢复且无重复写入，以及系统返回与读屏焦点。

微信小程序变体在 `purpose` 填写小程序窗口；自定义导航时在 `interactions` 说明标题、返回和胶囊的避让。由输入组件自动上推或页面布局负责键盘避让，在 `states` 写明键盘关闭后的栏位置。用实际微信小程序运行环境核对最后一个字段与提交栏、键盘开合有无二次上推，以及返回再次打开时是否按约定保留草稿。

### 带底部导航的列表

- `purpose`　浏览列表与查看详情，使用实际目标平台的手机导航布局展示。
- `navigation`　列表与收藏为顶级入口，列表项打开详情，返回恢复原列表位置。切换到收藏再返回列表时，保留列表筛选与滚动锚点。
- `interactions`　底部导航容器为系统栏留出空间，列表使用所分配的剩余可视区域。列表末项可滚到导航栏上方并打开。选中入口有文字标签和选中语义。
- `states`　展示加载、空、列表、失败与重试。重进优先恢复有效锚点，若该项目已移除则落到列表顶部。在较大字体下，列表项随内容增高。
- `exceptions`　详情的系统返回由路由栈处理。在支持交互式返回的设备上，取消保持详情，完成后恢复列表。HTML 演示标签与页面状态；原生交接复核底部 Insets、末项、锚点及读屏选中语义，按支持范围验证返回手势。
