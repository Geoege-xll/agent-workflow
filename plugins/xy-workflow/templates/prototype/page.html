页面职责

此源模板提供独立页面外壳，不代表已批准的业务设计。Platform: Web. Display: responsive. 内容按可用宽度自然展开，使用 CSS px，无固定窗口。创建实际页面时替换为批准的职责与范围；iOS／PC 固定预览须记录实际平台、宽高和显示比例。

导航

实际页面可直接离线打开；评审时通过插件prepare明确选择本页，由用户级不可变快照生成导航，不复制通用查看器或通信脚本到项目。已有项目目录如实际存在可保留圆形返回；评审包内返回只定位当前导航，不改写项目源。

画面后的唯一需求槽尚未绑定。实际交付须声明配置 plans 下的 Markdown 来源，并提供唯一 Markdown 普通相对链接；可选同名历史 HTML 链接仅在实际文件存在时提供。每个文档链接均以 target="_blank" 和 rel="noopener" 独立打开；计划 Markdown→HTML 生成链已退役，旧页过期不阻断 Markdown 修订，文档导航不属于画面渲染依赖。

交互

历史侧栏预留入口保持隐藏。当前评审由项目外工作台的浮动导航控件收放默认关闭的抽屉；不改变当前页或分组状态。

历史页面反馈预留入口保持隐藏。当前页面整改由工作台入口打开唯一编辑对话框，填写页面修改或新增；意见只作为修订输入，不产生批准。

页面契约：原生 summary 通过点击、Enter 或 Space 展开和折叠此五节，初始折叠，不覆盖产品画面。实际页面新增的重要产品操作须在此逐项映射稳定 ID。节点整改与 A 标记优先绑定产品插槽内唯一稳定 ID，匿名源元素使用派生来源键；动态无来源节点保留输入，由用户显式选有来源父层。交互条目自身可声明唯一 id，明确来源的接口引用使用 data-interface-ref 属性字面值（不推测或请求接口）。父子桥核对 source、origin、当前页与 token，父壳不跨 file:// 读取子 DOM。

状态

初始显示响应式产品插槽，五节契约折叠。标题、简述、画面、需求与平台说明依次可读；只有实际提供目录时才添加可选返回。评审快照采用固定设计视口相机缩放，浏览保留业务输入、按钮、滚动和导航，批注才拦截节点选择；导航默认收起，整改与标记由父工作台唯一状态维护，开发说明在独立对话框阅读。草稿、相机及撤回不进入 feedback 3 导出；JSON 与 Markdown 先经 validate 复核，再交当前授权作者修订，无意见等级或批准状态。源模板没有业务请求或提交，因此业务加载、成功、错误和弹窗状态不适用；实际页面需在本 HTML 实现获准状态。

页面特例

此源模板允许未绑定需求的空槽；真实交付页必须绑定正式需求。没有其他页面特例。复用中性共享外壳，产品 token 来自实际项目规范，不将外壳颜色当作产品主题或业务视觉批准。
